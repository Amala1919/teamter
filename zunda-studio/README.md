# zunda-studio

合成音声(VOICEVOX)によるゲーム実況動画を、**AIと会話しながら作る**デスクトップ動画編集ソフト。

想定する動画の形式は、**ずんだもん(投稿者本人の役)とAIが演じる相方の2人による掛け合い**である。投稿者はずんだもんのセリフを書き、AIは相方として設定された性格・口調に従って返答を書く。その会話がそのまま台本になり、音声・字幕・口パクを備えたタイムラインになる。

ゆっくりMovieMaker4(YMM4)の「テキストを打つと音声・字幕・口パクが1つのアイテムとして生成される」編集モデルを土台に、その上にAIを**共演者**として載せたものと言える。

## これは何を解決するのか

ずんだもん実況の制作でいちばん時間を食うのは、動画編集の操作そのものではなく**台本を書くこと**、とくに1人で2役の掛け合いを延々と書き続けることである。YMM4は台本をタイムラインに並べる作業を最小化したが、台本を書くのは人間のままだった。

zunda-studioでは、自分のセリフを書けば相方の返答がAIから返ってくる。会話として書き進めるだけで台本が埋まり、そのまま動画になる。相方の性格はプロジェクトに保存されるので、回を重ねてもキャラクターがぶれない。

編集面でも、「テンポが悪いから2割短く」「ここはツッコミなので表情を変えて」といったチャット指示でタイムラインを操作できる。手動編集も従来どおり可能で、AIは省略できる。

さらに**ゲームを録画している最中**にもAIに相談でき、その会話は録画上の時刻付きで記録される。編集時にそれを見返して「どこで何を話したか」を思い出し、そのやりとりをそのまま台本に採用できる。プレイ中に考えていたことは、あとから思い出せないからである。

## 状態

Phase 0〜7 を実装済み(台本と音声合成、PSD 立ち絵、素材・タイムライン・ズーム・書き出し、AI の相方と編集チャット、録画中のライブ、録画からの下書きと投稿文、自動保存・辞書・インストーラ)。その後、装飾(矢印・吹き出し・集中線など)・切り抜きと小窓・色の調整・切り替え・目印・音量の点・待ち時間の早送り・効果音のパレット・ひな形・縦型のショート・音の大きさをそろえる書き出しを足した。未着手は .ymmp の読み込みなど。進行状況と検証の状況は [docs/ROADMAP.md](docs/ROADMAP.md) を参照。

導入と使い方は [docs/SETUP.md](docs/SETUP.md) を参照。

## 開発

```sh
npm install
npm run dev            # Electron を開発モードで起動
npm run typecheck      # 型チェック
npm run test           # ユニットテスト
npm run test:e2e       # 画面のテスト(テスト用ホスト + Chromium)
npm run test:electron  # 実物の Electron での確認(先に npm run dist -- --dir)
npm run dist:win       # Windows のインストーラ
```

## 素材とライセンスについて

このリポジトリは**音声ライブラリ・立ち絵素材・BGMを一切同梱しない**。すべてユーザーが用意した素材を読み込む。

VOICEVOX ENGINEはアプリから自動起動する形で利用する。インストール済みの VOICEVOX を自動で探し、見つからなければ公式の配布物をダウンロードして入れられる(利用者がボタンを押したときだけ)。配布物を作るときに公式の VOICEVOX ENGINE を `vendor/voicevox-engine/` に置けば改変せずに同梱する。リポジトリにはバイナリを置かない(LGPL-3.0を含むデュアルライセンスのため、配布形態は [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) の「ライセンス要件」に従う)。

VOICEVOXの音声ライブラリは利用規約でクレジット表記が必要である。本アプリは使用したキャラクターを追跡し、`VOICEVOX:ずんだもん` 形式のクレジット文を自動生成する。ただし**最終的な規約遵守の責任は動画の投稿者にある**ため、生成されたクレジットの確認は必須とする。
