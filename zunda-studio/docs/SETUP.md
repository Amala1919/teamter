# 導入と使い方

zunda-studio を自分の PC で動かし、動画を1本作るまでの手順。外部のツールはどれも**無くてもアプリは起動する**。使いたい機能に必要なものだけ入れればよい。

| 使いたい機能 | 必要なもの |
| --- | --- |
| セリフの音声・字幕・口パク | VOICEVOX(アプリから自動で入れられる。AivisSpeech などの互換エンジンも可) |
| 動画の読み込み・プレビュー・書き出し | ffmpeg |
| 相方の返答・編集チャット・下書き・投稿文 | Claude Code CLI、または OpenCode の API キー |
| 録画中の「押しながら話す」 | whisper.cpp とモデルファイル |
| 録画との時刻合わせの自動化 | OBS Studio(WebSocket を有効にする) |

## 1. アプリを入れる

### 配布用のインストーラから

`zunda-studio Setup x.y.z.exe`(Windows)を実行する。インストーラの作り方は「7. 配布用に作る」を参照。

### ソースから動かす

[Node.js](https://nodejs.org/) の LTS 版(22 以上)を入れておく。

**Windows**: `zunda-studio` フォルダの **`起動.bat` をダブルクリック**する。初回と更新後は必要な部品を自動で入れ(数分かかる)、ビルドしてからアプリを開く。黒い画面を閉じるとアプリも終了する。開発中は `起動.bat dev` で開発モード(画面の変更がすぐ反映される)になる。

**macOS / Linux**、または手で動かす場合:

```sh
npm ci
npm run start   # ビルドして起動
npm run dev     # 開発モード
```

## 2. 音声エンジン(VOICEVOX)

**何も入れなくても使えます。** zunda-studio を起動して VOICEVOX が見つからないときは、上に「VOICEVOX(音声エンジン)が見つかりません」と出るので、**「自動で入れて起動」**を押します。公式の VOICEVOX ENGINE(CPU 版、1〜2GB 程度)をダウンロードして展開し、そのまま起動します。途中で止めても、次はダウンロード済みの分から続けます。**設定 → 音声エンジン**の「最新版を入れ直す」で更新もできます。

すでに VOICEVOX をインストールしている場合は、それを自動で探して起動します(Windows なら `%LOCALAPPDATA%\Programs\VOICEVOX\vv-engine\run.exe` など)。VOICEVOX を先に開いていれば、それにつなぎます。

- 見つからない場所に入れているときは、**設定 → 音声エンジン**で、エンジンの実行ファイル(`run.exe`)の場所を指定する。
- AivisSpeech などを使うときは、同じ画面の「AivisSpeech を追加」で接続先を足す。

**クレジットについて**: VOICEVOX の各キャラクターには利用規約があり、動画の概要欄などにクレジット(例: `VOICEVOX:ずんだもん`)が要る。zunda-studio は使ったキャラクターからクレジット文を作るが、**規約に合っているかの最終確認は投稿者が行う**(書き出し画面の「内容を確認した」)。

読みが違う語は、セリフを選んでインスペクタの「読み方」で直すか、**設定 → 音声エンジン → 読み方の辞書** に登録する。

## 3. ffmpeg

動画・音声の読み込み、プレビュー用の軽い動画(プロキシ)、波形、書き出しに使う。

**プレビューの画質**: タイムラインの「素材を追加」の横の「プレビュー画質」で、これから読み込む動画のプレビューの画質を選べる。読み込んだ後は、動画を選んでインスペクタの「プレビューの画質」で動画ごとに変えられる。書き出しは常に元の画質で行う。
- 自動(既定): そのまま再生できる形式なら元のファイルを使い、できなければ 540p の軽い動画を作る。
- 元の画質: そのまま再生できなければ、元の大きさのまま変換する(きれいだが、用意に時間がかかり再生も重い)。
- 1080p / 720p / 540p / 360p: その高さを上限にする。元がそれより大きければその高さの軽い動画を作る(4K や高フレームレートの録画でプレビューが重いときに下げる)。

- Windows: `winget install Gyan.FFmpeg`、または [ffmpeg.org](https://ffmpeg.org/download.html) から入手して展開する。
- macOS: `brew install ffmpeg`

PATH に通っていれば自動で見つける。通していなければ **設定 → ライブ・外部ツール → ffmpeg / ffprobe** で場所を指定する。

## 4. AI(Claude / OpenCode)

Claude は PC に入れた Claude Code を通して、OpenCode は API キーで呼び出す。Claude のログイン情報はアプリでは預からない。

### Claude(サブスクリプション)

1. [Claude Code](https://docs.claude.com/en/docs/claude-code/overview) をインストールする。
2. ターミナルで `claude` を起動し、`/login` でログインする。
3. zunda-studio の **設定 → AI** で、Claude の状態が「利用可能」になっていることを確かめる。

Claude のサブスクリプションをこの形で使えるのは**投稿者本人が自分の PC で使う場合**に限る。アプリを他人に配る場合は、API キー方式のプロバイダを足して置き換える必要がある。

### OpenCode(OpenCode Go など)

**API キーを入れるだけで使えます**(OpenCode をインストールする必要はありません)。

1. [OpenCode](https://opencode.ai/) のサイトにログインし、OpenCode Go を契約する。
2. 管理画面の「API Keys」でキーを発行してコピーする。
3. zunda-studio の **設定 → AI → OpenCode** の「API キー」に貼り付けて「保存して接続」を押す。状態が「利用可能」になれば使える。

入れたキーはこの PC の中だけに、OS の鍵保管庫(Windows は DPAPI、macOS はキーチェーン)で暗号化して保存します。画面には末尾の4文字だけが出ます。インストール済みの opencode コマンドを使いたい場合は「接続のしかた」で切り替えられます(そのときは opencode に登録している全てのプロバイダのモデルが出ます)。

モデルの一覧には、次の2つが見出しごとに出ます(1つのキーでどちらも使えます)。

- **OpenCode Go(月額プラン)**: Kimi・GLM・DeepSeek・Qwen・MiniMax・MiMo・GPT Luna・Grok など
- **OpenCode Zen(従量課金)**: Claude・GPT・Gemini・Grok・Kimi・GLM など。「無料」と付いたモデルもある。使った分だけ料金がかかるので、残高を確認して使うこと

「契約しているプラン」で選んだ方から、おすすめを選びます。一覧はアプリに内蔵した控え(models.dev の 2026-09-27 時点)と、キーを入れたあとに OpenCode から取った実際の一覧を合わせたものです。新しく出たモデルが一覧に無いときは「その他(モデルIDを入力)」で `opencode-go/モデル名` や `opencode/モデル名` の形で指定できます。

OpenCode Go はコーディングエージェント向けのサービスである。利用条件は各自で確認すること。

### 役割ごとに AI を選ぶ

**設定 → AI** で、2つの役割それぞれにプロバイダとモデルを選ぶ。

- **会話AI(相方)**: 相方の返答と、録画中のライブの会話に使う。プロジェクトごとに台本画面の「相方の中の人」で変えられる(回ごとに中の人を変える企画にも使える)。
- **編集AI**: 編集チャット・録画からの下書き・投稿文に使う。

モデルの一覧は、上に**おすすめ**、下に**その他のモデル**として、使えるものが全て出る(一覧に無いモデルは「その他(モデルIDを入力)」で指定できる)。「接続テスト」で返事が来れば使える。ログインしていない・上限に達した、などのときは、画面に原因と対処が出る。

## 5. 録画中の相談(ライブ)

### whisper.cpp(押しながら話す)

1. [whisper.cpp](https://github.com/ggml-org/whisper.cpp) のリリースから、自分の OS 用の `whisper-cli` を入手する。
2. モデルファイル(例: `ggml-small.bin`。日本語なら small 以上を推奨)を入手する。
3. **設定 → ライブ・外部ツール** で、whisper-cli とモデルファイルの場所を指定する。

声は PC の中で文字にし、外へは送らない。録った声は文字起こしにだけ使い、動画の音声には使わない。

### OBS との連携

1. OBS の **ツール → WebSocketサーバー設定** で「WebSocketサーバーを有効にする」をオンにし、パスワードを決める。
2. zunda-studio の **設定 → ライブ・外部ツール → OBS 連携** をオンにし、接続先(既定 `ws://127.0.0.1:4455`)とパスワードを入れる。

これで、録画を始めた時刻と会話の時刻が自動で対応付けられる。OBS を使わない場合も、編集時に「合わせる」で手で合わせられる。

## 6. 動画を1本作る流れ

1. **キャラクター**: 台本の「ずんだもん(あなた)と四国めたん(AI)を追加」を押す。キャラクター画面で相方の性格・口調を書き、立ち絵の PSD を選ぶ(目・口・眉は自動で推定され、「パーツと表情を設定」で直せる)。
2. **(録画しながら)ライブ**: 右の「ライブの記録」→「ライブを始める」で小さなウィンドウが開く。録画中に相方と話したり、ホットキー(既定 Ctrl+Shift+M)で目印を打ったりする。
3. **素材**: タイムラインの「素材を追加」でゲームの録画・BGM・画像を入れる。
4. **下書き(任意)**: チャットの「録画から下書き」で、録画とライブの記録から区間と掛け合いの下書きを作らせ、変更点を見て適用する。ライブの記録の「台本に使う」で、録画中の会話をそのままセリフにもできる。
5. **台本**: 自分のセリフを書き、「相方の返答を生成」で相方の返事の案を選ぶ。「画面」で「再生位置の画面を見せる」「区間の映像を見せる」を選ぶと、ゲームの録画のコマを画像として相方に見せ、画面の出来事も踏まえた返事を作らせられる(区間は長さに応じて最大8コマ。画像を読めるモデルが必要で、読めないモデルなら文字だけで作ったと表示する)。
6. **演出**: 「ズーム枠を置く」で寄りたい範囲を枠で決める。エフェクトやテロップはインスペクタで付ける。チャットで「テンポを上げて」のように頼むこともできる。
7. **書き出し**: ツールバーの「書き出し」で mp4 を作る。同じ画面で、タイトル案・概要欄・チャプターを作り、クレジットを確認して概要欄のテキストを保存する。SRT(字幕ファイル)もここで保存できる。

### 編集の操作

タイムライン・プレビュー・台本は**右クリック**でその場の操作が出る(分割・静止画・コピー・貼り付け・複製・削除して詰める・空白を詰める/入れる・速度・音量・フェード・動き・ズーム枠・レイヤーの移動・ロックなど)。よく使うものはキーでも操作できる。

| キー | 操作 |
| --- | --- |
| Space | 再生・停止 |
| S | 再生位置で分割(選んでいなければ、再生位置にあるものを全て) |
| F | 再生位置のコマで動画を止めて、2秒の静止画を挟む(後ろはずれる)。Shift+F は、動画のその先を静止画に置き換える |
| Ctrl+C / Ctrl+X / Ctrl+V | コピー / 切り取り / 再生位置に貼り付け |
| Ctrl+D | すぐ後ろに複製 |
| Delete / Shift+Delete | 削除 / 削除して詰める |
| Ctrl+A | すべて選択 |
| ← / → | 1コマ戻る・進む(Shift を押しながらで1秒) |
| ↑ / ↓ | 前・後の編集点(アイテムの端)へ |
| Home / End | 先頭・末尾へ |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |

**静止画(フリーズフレーム)**: 再生位置を止めたい所に置き、動画を右クリックして「再生位置で止めて静止画を挟む」から長さを選ぶ(F キーなら2秒)。止める直前に映っていたコマがその間映り続け、音は止まる。ズームで寄っている途中で止めると、止めている間も寄ったまま。静止画の長さはあとからタイムラインの端をつまんで変えられる。

**立ち絵の調整**: 立ち絵を付けると、タイムラインの立ち絵のレーンに「立ち絵: 名前」の区間(動画の最後まで)が置かれる。この区間を選ぶと、インスペクタで位置・大きさ・表情を数値で直せ、区間の長さを変えたり消したりすると、その間だけ立ち絵が出る。プレビューの立ち絵をクリックすると枠が出て、ドラッグで動かし、四隅で大きさを変えられる(ふだんは動画全体の配置が変わる)。場面ごとに変えたいときは、立ち絵を右クリックして「この場面だけ動かせるようにする」「この場面で隠す」「この場面の表情」を選ぶ(再生位置のセリフの間が対象)。タイムラインのレーンを右クリックして「ここに立ち絵の区間を置く」から、登場(ふわっと・ぽんっと)・隠す・位置や表情を変える区間を置くこともできる。区間を選ぶとインスペクタで種類・表情・配置・登場の動きを変えられる。何も選んでいないときのインスペクタで、話していない人を暗くする・話し始めに跳ねる(話し手の強調)を設定できる。ほかの編集が終わったら、チャットの「立ち絵をAIで調整」で、セリフの感情や場面(ズームなど)に合わせた表情・出し入れ・位置・強調をまとめて提案させられる(セリフの文や尺は変えない。変更点を見てから適用し、1回の「元に戻す」で全部戻せる)。

**フリー BGM・効果音**: タイムラインの「フリー素材サイト」で、ゆっくり・ずんだもん実況でよく使われる配布サイトの一覧(利用条件・クレジットの要否・表記の例・規約へのリンク)を見られる。「戦争・歴史もの向き」で絞ると、HoI4 のような重い雰囲気に合う曲の多いサイトが出る。曲や音は各サイトから入手して「素材を追加」で取り込む(どのサイトも素材の再配布を禁じているため、アプリには入っていない)。取り込んだ素材は、インスペクタの「入手元サイト」でサイトを選ぶと、入手元とクレジット表記が埋まり、書き出し画面の概要欄の下書きに自動で入る。表記が必要なサイトは必ず、任意のサイトも既定で載る(外すこともできる)。魔王魂・MusMus・PeriTune などは、ファイル名から自動で判定する。

**便利な操作**:
- **台本の検索・置換**: Ctrl+F(または台本の欄の「検索」)で検索欄が出る。Enter / Shift+Enter で見つかったセリフへ移る。大文字・小文字と全角・半角の英数字は区別しない。話者で絞り込めて、「すべて置換」は1回の「元に戻す」で全部戻せる。
- **最近開いたプロジェクト**: ツールバーの「最近 ▾」から、開いた・保存したプロジェクトを選んで開ける(10件まで。見つからなくなったものは一覧から外れる)。
- **今の画面を画像で保存**: プレビューを右クリックして「この画面を画像で保存(PNG)」。動画と同じ大きさで保存する。サムネイルの素材には「字幕なし」が便利。
- **まとめてずらす**: 目盛りやレーンを右クリックして「ここから後ろをすべて選択」を選び、選んだものの1つをドラッグすると、選んだもの全部が同じだけ動く(1回の「元に戻す」で戻る)。Shift+クリックで選ぶものを足してもよい。
- **素材は独立、合わせたいものはグループに**: セリフを書き換えて長さが変わっても、ほかのセリフや素材は動かない(伸びたセリフが次と重なったら、自分で動かす)。一緒に動かしたいもの(セリフとその場面の画像・テロップなど)は、Shift+クリックで選んで右クリック →「グループにする」(Ctrl+G)。グループの1つをクリックするとグループごと選ばれ、ドラッグすると一緒に動き、グループのセリフの長さが変わると、グループのうちそのセリフより後ろのものが一緒にずれる。解くときは右クリック →「グループを解く」(Ctrl+Shift+G)かインスペクタの「グループを解く」。
- **キーの操作の一覧**: F1 かツールバーの「?」。
- **閉じるときの確認**: 保存していない変更があるときに閉じようとすると、閉じてよいか確かめる。

**画面の配分**は、欄と欄の境目(細い線)をドラッグして変えられる。次に開いたときもそのまま。境目をダブルクリックするとその境目が、右クリックの「すべての欄の大きさを元に戻す」で全体が元に戻る。

保存していない変更は 15 秒ごとに自動で控えを取る。アプリが落ちても、次に起動したときに復元できる。

## 7. 配布用に作る

```sh
npm run dist:win     # Windows のインストーラ(dist/ に出る)
npm run dist:mac     # macOS
npm run dist -- --dir  # インストーラにせず展開したまま作る(動作確認用)
```

VOICEVOX ENGINE を同梱したい場合は、公式の VOICEVOX ENGINE を改変せずに `vendor/voicevox-engine/` に置いてから作る(ライセンス文書も一緒に置くこと)。同梱したエンジンは、インストール済みの VOICEVOX より先に使われる。

## 8. 困ったとき

| 症状 | 対処 |
| --- | --- |
| 起動時に `Electron uninstall` と出る | Electron 本体が入っていない。最新の `起動.bat` なら自動でダウンロードする。手で直すときは `npx install-electron` |
| セリフが「合成できません」になる | 上に出る「自動で入れて起動」で VOICEVOX を入れるか、設定 → 音声エンジンの状態を確かめる。上部に出る「すべて再試行」で合成し直せる |
| VOICEVOX の自動インストールが失敗する | ネットにつながっているか確かめて「もう一度試す」。会社のネットワークなどで GitHub からのダウンロードが止められているときは、VOICEVOX を公式サイトから入れる |
| OpenCode が「API キーを入力してください」になる | 設定 → AI → OpenCode でキーを入れ直す。キーが正しくないか、契約が切れている |
| 動画を入れると「編集用の動画を作成中」が出る | 画面でそのまま再生できない形式(HEVC の mkv など)なので、軽い動画を作っている。終わるまで待つ(書き出しは元の動画から行う) |
| AI の返事が来ない | 設定 → AI の接続テストで原因を確かめる。Claude はログインが切れていれば claude でログインし直す |
| 押しながら話しても文字にならない | 設定 → ライブ・外部ツールで whisper-cli とモデルの場所を確かめる。OS のマイクの許可も確かめる |
| 録画と会話の時刻がずれる | ライブの記録で発言を選び「合わせる」→ プレビューをその場面に動かして「ここに合わせる」 |

## 9. 開発者向け

```sh
npm run typecheck      # 型チェック
npm run test           # ユニットテスト(本物の ffmpeg と模擬の VOICEVOX / CLI を使う)
npm run test:e2e       # 画面のテスト(テスト用ホスト + Chromium)
npm run dist -- --dir && npm run test:electron   # 実物の Electron での確認(画面の無い環境では xvfb-run の下で)
```

テストでは、本物と同じ API を返す模擬の VOICEVOX(`tests/fixtures/mock-voicevox.mjs`)と、決まった応答を返す模擬の Claude / OpenCode / whisper(`tests/fixtures/bin/`)を使う。本物の AI や音声エンジンが無くても全てのテストが動く。
